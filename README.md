El objetivo de este proyecto es diseñar una placa de circuito impreso (PCB) para construir una mezcladora de audio estéreo básica.

El equipo dispondrá de dos entradas de audio: una entrada de línea estéreo y una entrada para micrófono, cuya ganancia podrá ajustarse de forma independiente.

La salida proporcionará la mezcla de ambas fuentes de audio, conservando la señal en formato estéreo..
